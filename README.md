# sales-forecasting-time-series-analysis


README.md
Sales Forecasting using ARIMA, Prophet & LSTM
Project Overview

This project focuses on forecasting future retail sales using historical time-series data. The system applies statistical, machine learning, and deep learning forecasting techniques to identify:

Sales trends
Seasonal patterns
Promotional impacts
Future revenue forecasts

The project demonstrates real-world business analytics and demand forecasting used in retail and e-commerce industries.

Objectives
Predict future sales using historical data
Analyze trends and seasonality
Measure promotional impacts on sales
Compare forecasting algorithms
Visualize forecast vs actual sales
Dataset
